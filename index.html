كيف يتصرف البرنامج؟
• PDF نصي سليم → استخراج مباشر وسريع.
• PDF بعربي بترميز مكسور → يكتشف المشكلة ويحوّل الصفحة تلقائيًا إلى OCR عربي.
• PDF سكان/صورة → OCR تلقائي.
• الملف المختلط عربي + إنجليزي + أرقام → OCR يستخدم العربية والإنجليزية عند الحاجة.
